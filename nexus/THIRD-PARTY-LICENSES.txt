5. Game content and parameter data
----------------------------------
The DLL patches the game in memory; this archive ships no regulation.bin and no unpacked game
files. Two things in it are derived from game data:

  * mod/script/talk/m00_00_00_00.talkesdbnd.dcx (also inside the installer payload) - a
    modified copy of the vanilla talk ESD. The grace-menu patch needs this file mounted through
    the mod loader; without it the "Comrades" entry cannot be injected. It is a modification of
    ELDEN RING game data, not original content, and it is included only so that this mod works.
    Do not redistribute it on its own.
  * tables/convergence/er_echo_equip.json and er_echo_magic.json - numeric parameter-ID lists
    dumped at runtime from the game's own regulation data; the exporter uses them to check that
    an item ID really exists. They contain no files, models, textures or code from
    The Convergence - only plain numbers. The numbers reflect a Convergence-installed regulation
    because that is the environment they were dumped in.

The optional "root menu ESD fallback" archive carries a second variant of the same talk ESD
(root-menu layout) plus the switch script.

ELDEN RING is a trademark of FromSoftware, Inc. and Bandai Namco Entertainment. This mod is
an unofficial fan work, not affiliated with or endorsed by either company.


6. Note on machine learning
---------------------------
This mod ships no AI models. It contains an optional bridge script that can call a language
model API chosen by the user at runtime; that is not part of this archive's content and is
disabled by default (mock mode). The fromsoftware-rs NON-AI restriction (§2) still applies to
the compiled DLL.
