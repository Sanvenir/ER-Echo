# 多语言（菜单文案）

ER Echo 自己往游戏里写的文字只有赐福菜单那几行（`mod/src/ui.rs` → `mod/src/i18n.rs`）。
游戏原版文本（物品名、赐福名……）不受影响，它们还是走游戏自己的 FMG。

## 1. 语言从哪来

`er_echo.ini` → `[i18n] language=` 决定菜单文案语言：

| 写法 | 含义 |
|---|---|
| `game` | **默认 / 推荐**：跟随**游戏自己的文本语言**（下面详述） |
| `auto` | 跟 **Windows 显示语言**：简中→`zh-CN`，繁中/港台→`zh-TW`，日文→`ja`，其他→`en` |
| `zh-CN` / `zh-TW` / `en` / `ja` | 写死 |
| 其他代码（`ko`、`de`…） | 自定义语言，需要 `er_echo_i18n.ini` 提供文案 |

内置语言：

| 代码 | 语言 | 说明 |
|---|---|---|
| `zh-CN` | 简体中文 | |
| `zh-TW` | 繁體中文 | |
| `en` | English | 所有缺键的兜底语言 |
| `ja` | 日本語 | |

**游戏文本语言**（`language=game`）的解析顺序，拿到就停：

1. 进程里的 `steam_api64.dll` → `ISteamApps::GetCurrentGameLanguage`
   —— 游戏自己读的就是这个值（Elden Ring 没有「游戏内语言」选项，语言由 Steam 的
   per-game 语言决定）；Goldberg 之类模拟器也实现这个接口；
2. `<Steam 库>\steamapps\appmanifest_1245620.acf` 的 `UserConfig` → `MountedConfig`；
3. 模拟器配置：`%APPDATA%\Goldberg SteamEmu Saves\settings\language`，
   或 `<Game>\steam_settings\configs.user.ini` 的 `language=`；
4. 都拿不到 → Windows 显示语言（等同 `auto`）。

所以 `game` 最坏情况也只是退化成 Windows 显示语言（等同 `auto`）。
注意：游戏语言是法/德/韩…时 `game` 会解析成 `fr` / `de` / `ko`，但内置只有
中/繁/英/日——该语言没有内置文案会回退英文，想显示对应文字就用 `er_echo_i18n.ini` 补。

> 想改游戏文本语言：Steam 库 → ELDEN RING 右键 → 属性 → 通用 → 语言。
> 改完 ER 的文本语言变了，菜单重启后自动跟着变。

日志里会写实际生效值和来源：

```text
i18n: language=en (source=manifest, config ...\mods\ER-Echo\er_echo.ini: loaded,
                   language="game", override file absent, builtin: zh-CN,zh-TW,en,ja)
```

`source=` 是 `steam` / `manifest` / `goldberg` / `windows` / `config` 之一；
`status` IPC 的 `ui.language` / `ui.language_source` 也是这两个值。

> 配置文件（`er_echo.ini`）**没读到**时，DLL 用内置默认值，其中 `language` 是 `game`。
> 所以「菜单怎么变英文了」先看日志这一行：`config <路径>: loaded / not read — defaults`。

> **安装器**：`ER-Echo-Setup.exe` 的「安装 / 配置」页有独立的**「游戏内菜单语言」**下拉框
> （默认「跟随游戏文本」），和窗口顶部的**「安装器界面语言」**是两回事；改了会立刻写进
> `er_echo.ini`（先备份），重启游戏生效。安装时也按这个下拉框写。
> 安装器界面选 English 时，安装日志、状态和错误提示也会是英文（`setup_core` 的
> `set_ui_lang()`）；中文界面同理。CLI 也可以只改语言：
> `ER-Echo-Setup.exe --set-language "<Game>\mods\ER-Echo\er_echo.ini" game`。


## 2. 配置

`er_echo.ini`：

```ini
[i18n]
language=game
```

可选值：`game` / `auto` / `zh-CN` / `zh-TW` / `en` / `ja`，或**任意自定义代码**
（`ko`、`de`、`fr`……，需要配合下面的覆盖文件）。大小写、下划线都兼容
（`GAME`、`zh_CN`、`CHS`、`jp` 都认）。

改完重启游戏（DLL 启动时读一次）；也可以运行时切（`game` 也支持，切完按当前游戏语言解析）：

```powershell
python er-echo\tools\ipc_client.py set_language --args "{\"lang\":\"game\"}"
```

只改 ini 不重装（安装器 CLI，改前自动备份）：

```powershell
python er-echo\tools\er_echo_setup.py --set-language "<Game>\mods\ER-Echo\er_echo.ini" game
```

## 3. 自定义 / 覆盖：`er_echo_i18n.ini`

放在游戏根目录（和 `er_echo.dll` 同级），UTF-8（带不带 BOM 都行）：

```ini
[en]
root=Comrades ({count}/{n})
resummon=Resummon now

[ko]
root=동료 ({count}/{n})
count_row=파티 인원: {count} (클릭하여 변경)
```

规则：

* `[section]` 是语言代码；只写想改的键，没写的回退到内置（该语言没有就回退英文）；
* 值里的 `{count}` `{n}` `{i}` `{name}` `{level}` 是占位符，**不要翻译/删除**，
  写错了会原样显示出来（方便发现拼写错误）；
* `;` 和 `#` 开头是注释；`key=value` 只按第一个 `=` 切分，值里可以有 `=`；
* 文件不存在 = 只用内置文案；写坏了不会崩，最坏情况就是回退英文。

发布包里带了一份 `er_echo_i18n.example.ini`（全部注释掉的示例），
复制成 `er_echo_i18n.ini` 再改。

## 5. 加一门新语言（不用重编译）

1. 复制 `er_echo_i18n.example.ini` → `er_echo_i18n.ini`；
2. 加一段 `[ko]`（或任何代码），把上面「键表」里的键写全；
3. `er_echo.ini` 里写 `language=ko`；
4. 重启游戏，日志里应出现
   `i18n: language=ko (source=config, config ... language="ko", override file loaded, ...)`。

## 6. 已知限制

* **字体**：菜单文字由游戏当前语言的字体图集渲染（游戏只加载当前语言那一套字形）。
  `language=game` 就是为了和游戏文本一致、避免方块；如果你**故意跨语言**
  （例如英文游戏里写 `language=zh-CN`），可能看到方块——那是字体问题，不是配置没生效；
* 日志（`er_echo.log`）和命令行工具的输出仍是中文，属于开发者面向，不在本地化范围；
* 菜单里的档案名、等级数字来自你的 profile，不翻译；
* `—`（空位占位符）是语言无关的。

## 7. 排查

| 现象 | 检查 |
|---|---|
| 在安装器里改了语言，进游戏没变 | 是否重启游戏（DLL 只在启动时读一次）；`er_echo.ini` 的 `[i18n] language=` 是不是你选的值（安装器会立刻写，日志会打印 `[ok] … [i18n] language=`）；再看 `er_echo.log` 的 `i18n: language=` |
| 改语言时弹 `Permission denied` | 先看弹框里的路径是不是你的游戏目录：如果是 `%TEMP%` / 已删除目录，关掉安装器重开（会自动重新检测，坏的“上次路径”不会再被使用）；确实是 Program Files 权限就点弹框里的「以管理员身份写入」，或右键 exe →「以管理员身份运行」 |
| 菜单还是旧语言 | 是否重启；`er_echo.log` 里 `i18n: language=` 是什么 |
| `language=game` 却是英文 | 游戏本身现在就是英文：Steam 库 → ELDEN RING 右键 → 属性 → 通用 → 语言。日志 `source=` 是 `steam`/`manifest` 就说明读的是游戏语言；想固定中文就写 `language=zh-CN` |
| 菜单突然变英文 | 看日志的 `config <路径>: loaded`：<br>`not read — defaults` = 配置没读到（文件不在 / 被占用），DLL 兜底 `game`；<br>`loaded` + `language="en"` = 配置里写死了 `en`，改成 `game` / `auto` / `zh-CN` |
| 换成插件布局后变英文 | 旧版平铺的 `<Game>\er_echo.ini` 里写了 `auto`，而新装的 `mods\ER-Echo\er_echo.ini` 是安装器模板（`game`）。**新安装器会沿用旧 ini**；老安装器装的版本手动把 `language=` 抄过去 |
| 自定义语言没生效 | 文件是否叫 `er_echo_i18n.ini`（不是 `.example`）；section 代码是否和 `language=` 一致 |
| 占位符原样显示 | 键名拼错或占位符写错（`{Count}` 不等于 `{count}`） |
| 显示方块 | 语言和游戏文本语言不一致，或该语言字体缺失（见 §6）；改成 `game` 或把游戏语言改成一致 |
| 菜单空白 | 消息钩子没装上（AOB 不匹配），不是语言问题：看 `ui: message hook installed` |
